# 启动配置与服务端口

本机 `.env` 只负责启动配置，发行包附带不含秘密的 `.env.example`。
管理 UI 和管理 API 共用 `HEREDITY_UI_PORT`，未配置时使用 5099。
启动端口优先级为显式 `--ui-port`、进程环境、`.env`、内置默认值。
配置内容不会作为 shell 执行，也不进行变量或命令替换。

“配置”页通过已登录的管理 API 读取公开端口信息，并只允许保存 `ui_port`。
保存使用原子替换，保留文件中其他键和注释；秘密键不返回浏览器。
新的管理端口在下一次启动时生效，不自动中断平台会话。

每个注册接口拥有自己的监听地址与端口。创建两个服务并分别设置端口 2000 和 9999，
宿主就在这两个端口启动对应服务；不另加固定 OneBot 端口，也不额外映射端口。
端口 0 只在显式选择时让系统分配临时端口，实际值在列表显示。

端口占用返回 `PORT_IN_USE`；其他绑定错误返回 `NETWORK_BIND_FAILED`。
服务保持失败状态，端口不被悄悄替换。用户修改配置或解除冲突后可点击重试。
仅保存管理端口不预占该端口，真正启动时仍以系统绑定结果为准。

管理路由：

```text
GET /api/heredity/settings
PUT /api/heredity/settings {"ui_port": 5109}
GET /api/heredity/attention
```

侧栏注意标记聚合网络启动错误、活跃模块待分配、插件会话错误、
商场目录或安装包校验错误，以及待重启生效的配置。
提示只使用固定描述，不暴露票据、令牌、原生异常或本机绝对路径。
